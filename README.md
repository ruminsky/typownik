# Typownik

Prywatne narzędzie do typowania meczów piłkarskich (5 największych lig, Championship, 1. Liga, puchary europejskie, reprezentacje).

- Aplikacja: https://ruminsky.github.io/typownik/ (dodaj do ekranu początkowego w Safari)
- Dane aktualizują się same dwa razy dziennie (GitHub Actions, `.github/workflows/update.yml`).
- Źródła: Sky Sports, 90minut.pl, eloratings.net, FotMob, The Odds API, API-Football, RSS polskich portali i BBC.
- Klucze API są w ustawieniach repozytorium jako sekrety `ODDS_API_KEY` i `API_FOOTBALL_KEY`.

Prognozy to prawdopodobieństwa, nie pewniaki. Graj odpowiedzialnie.
